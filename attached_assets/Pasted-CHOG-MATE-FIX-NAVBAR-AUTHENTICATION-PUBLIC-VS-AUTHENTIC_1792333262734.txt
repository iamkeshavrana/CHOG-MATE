==================================================
PUBLIC / NOT LOGGED IN
==================================================

When the visitor has NO active CHOG MATE account/session:

Navbar should show ONLY:

- Home / Landing
- Discover
- Connect Wallet

Do NOT show authenticated navigation items such as:

- My Profile
- Messages
- My Chog
- Matches
- Notifications
- Settings
- other private/account navigation

The user must be able to browse:
Landing/Home
Discover

without creating an account.

==================================================
PUBLIC DISCOVER
==================================================

Discover must remain publicly browsable without login.

Anonymous users can:
- view real registered Chog holder profiles
- view real Chog NFT image
- view profile information
- view Chog number/tier where appropriate
- browse discovery cards

Anonymous users CANNOT:
- Like
- Pass
- Super Like
- Message
- Match
- Gift $CHOG
- Call
- access private account pages

If an anonymous user attempts an authenticated action, show a professional Connect Wallet / Create Account prompt.

Do not create an account merely because someone opens Discover.

==================================================
AUTHENTICATED / ACCOUNT SESSION
==================================================

Once a real CHOG MATE account/session exists after:

Connected wallet onboarding
OR
Manual public wallet-address onboarding

show the authenticated navbar.

Authenticated navigation can include the existing:

- Home
- Discover
- Matches
- Messages
- My Chog
- My Profile
- Notifications
- Settings

Use the existing application's actual route names/components where possible.

Do not create duplicate pages if they already exist.

==================================================
IMPORTANT — ADDRESS-ONLY ACCOUNTS
==================================================

Manual wallet-address onboarding creates a REAL persistent CHOG MATE social account.

Therefore:

Before account creation:
→ only Home + Discover + Connect Wallet

After successful address-only account creation/session:
→ authenticated navbar becomes available

However, address-only accounts are NOT connected blockchain wallets.

Therefore:
- social/profile/discovery features can work
- paid blockchain actions still require actual connected wallet

For:
Super Like
$CHOG Gift
any blockchain transaction

show:
"Connect your wallet to continue."

Never treat the manually entered address as a signer.

==================================================
SESSION STATE
==================================================

Navbar visibility must be based on the actual CHOG MATE authentication/session state.

Do NOT use:
- arbitrary localStorage flags
- "wallet address exists" alone
- frontend-only booleans that can become stale

Correct behavior:

NO ACTIVE SESSION
→ Public navbar

VALID CHOG MATE SESSION
→ Authenticated navbar

SESSION EXPIRED/LOGGED OUT
→ Public navbar immediately

If the user refreshes:
- restore the correct session state
- show the correct navbar

If the user logs out:
- private navbar disappears
- public navbar returns
